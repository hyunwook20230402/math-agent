# 문제 등록 규칙

## 필드

### `unit` (필수) — "과목 > 대단원 > 중단원"
예: `"공통수학1 > 다항식 > 다항식의 연산"`, `"미적분 > 수열의 극한 > 급수"`

### `category` — 교재명
| 값 | 설명 |
|----|------|
| `'쎈'` | 쎈 교재 |
| `'모의고사'` | 수능/모의고사 기출 |
| `'연산'` | 연산 교재 |
| `'자작'` | 자작 문제 |

### `difficulty_score` — 1~4 정수, 4단계 Lv1~Lv4 (**쓰기 컬럼**)

**2026-06-21 4단계 전환.** 옛 1~10 체계 폐기. 해설지에 인쇄된 Lv 라벨을 그대로 쓴다.

난이도 근거 우선순위:
1. **해설에 인쇄된 Lv 라벨** (Lv1~Lv4) — 가장 신뢰도 높은 실측. Call A(VL)가 해설 이미지에서 읽어 `difficulty_level` 로 받고, `Lv1→1 … Lv4→4` 로 환산.
2. **정답률(%)** — 과거 해설 호환용. Lv 라벨이 없고 정답률만 있으면 구간매핑(80%↑→1, 50~80%→2, 30~50%→3, 30%↓→4).
3. **구조 신호 추정** — 둘 다 없으면 VL이 1~4 추정.

매핑 코드는 `pipeline/difficulty_resolver.py`.

| score | Lv | 라벨 (`difficulty` 파생) | 화면 표기 | 구조 신호(라벨 없을 때) |
|-------|----|--------------------------|-----------|--------------------------|
| 1 | Lv1 | `very_easy` | 쉬움 | 공식 1개 직접 대입, 개념 1개 내 2~3단 계산 |
| 2 | Lv2 | `easy` | 보통 | 조건 2~3개 조합, 개념 1~2개 |
| 3 | Lv3 | `hard` | 어려움 | 아이디어 1개 — 경우분리 2개 / 그래프+대수 / 합성·역·절댓값 1개 / 개념 2~3개 복합 중 1개 |
| 4 | Lv4 | `very_hard` | 최고난도 | 다음 중 **2개 이상** — 경우분리 3+ / 합성·역·절댓값 중첩 2+ / 미지수 2+ 동시 결정 / 그래프+경우분리+대수 모두 / 개념 3+ 복합 |

- `difficulty` 는 GENERATED ALWAYS AS … STORED — insert 포함 금지. `difficulty_score: 3` 넣으면 DB 가 `difficulty='hard'` 자동 파생.
- 옛 1~10 데이터는 그대로 둠(미변환). 파생 라벨·프론트 표시는 옛값(5~10)을 모두 `very_hard`(Lv4)로 흡수해 깨지지 않게 처리. 재태깅 시 새 1~4 값으로 갱신.

### `answer_type`
- `'multiple_choice'` — 객관식 5지선다
- `'short_answer'` — 주관식

### `choices` ⚠️ 중요
**반드시 `null` 또는 `[]`. 보기 내용 채우지 말 것** (이미지 기반 문제라 보기는 이미지에서 확인).

```typescript
choices: null    // ✅
choices: []      // ✅
choices: ['①...', '②...']  // ❌
```

### `title` — 자동 생성 형식
`"{교재} {과목} {문제번호}번"` (예: `"쎈 공통수학1 42번"`)

## 과목 목록
공통수학1, 공통수학2, 미적분, 확률과 통계, 기하, 대수
