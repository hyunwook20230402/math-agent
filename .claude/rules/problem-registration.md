# 문제 등록 규칙

## 필드

### `unit` (필수) — "과목 > 대단원 > 중단원"
예: `"공통수학1 > 다항식 > 다항식의 연산"`, `"미적분 > 수열의 극한 > 급수"`

### `category` — 교재명
| 값 | 설명 |
|----|------|
| `'쎈'` | 쎈 교재 |
| `'모의고사'` | 수능/모의고사 기출 |
| `'연산'` | 연산 교재 |
| `'자작'` | 자작 문제 |

### `difficulty_score` — 1~4 정수, 4단계 Lv1~Lv4 (**쓰기 컬럼**)

**2026-06-21 4단계 전환.** 옛 1~10 체계 폐기. 해설지에 인쇄된 Lv 라벨을 그대로 쓴다.

난이도 근거 우선순위:
1. **해설에 인쇄된 Lv 라벨** (Lv1~Lv4) — 가장 신뢰도 높은 실측. Call A(VL)가 해설 이미지에서 읽어 `difficulty_level` 로 받고, `Lv1→1 … Lv4→4` 로 환산.
2. **정답률(%)** — 과거 해설 호환용. Lv 라벨이 없고 정답률만 있으면 구간매핑(80%↑→1, 50~80%→2, 30~50%→3, 30%↓→4).
3. **구조 신호 추정** — 둘 다 없으면 VL이 1~4 추정.

매핑 코드는 `pipeline/difficulty_resolver.py`.

| score | Lv | 라벨 (`difficulty` 파생) | 화면 표기 | 구조 신호(라벨 없을 때) |
|-------|----|--------------------------|-----------|--------------------------|
| 1 | Lv1 | `very_easy` | 쉬움 | 공식 1개 직접 대입, 개념 1개 내 2~3단 계산 |
| 2 | Lv2 | `easy` | 보통 | 조건 2~3개 조합, 개념 1~2개 |
| 3 | Lv3 | `hard` | 어려움 | 아이디어 1개 — 경우분리 2개 / 그래프+대수 / 합성·역·절댓값 1개 / 개념 2~3개 복합 중 1개 |
| 4 | Lv4 | `very_hard` | 최고난도 | 다음 중 **2개 이상** — 경우분리 3+ / 합성·역·절댓값 중첩 2+ / 미지수 2+ 동시 결정 / 그래프+경우분리+대수 모두 / 개념 3+ 복합 |

- `difficulty` 는 GENERATED ALWAYS AS … STORED — insert 포함 금지. `difficulty_score: 3` 넣으면 DB 가 `difficulty='hard'` 자동 파생.
- 옛 1~10 데이터는 그대로 둠(미변환). 파생 라벨·프론트 표시는 옛값(5~10)을 모두 `very_hard`(Lv4)로 흡수해 깨지지 않게 처리. 재태깅 시 새 1~4 값으로 갱신.

### `answer_type`
- `'multiple_choice'` — 객관식 5지선다
- `'short_answer'` — 주관식

### `choices` — 기본은 비워 두고, **답이 수식일 때만** 채운다 (2026-08-27 갱신)

지면에 보기(①~⑤)가 인쇄된 문제는 **비워 둔다**(`null` 또는 `[]`). 학생 화면이 문제 이미지를
보여주고 번호만 고르게 하므로 보기 내용을 옮겨 적을 이유가 없다.

다만 **"나머지를 구하시오" 처럼 답이 일차식·이차식인 문제**는 주관식 칸(숫자 입력)에 담을 수
없다. 이때는 교사가 객관식으로 바꾸고 보기를 직접 만든다 — CMS 상세 입력·문제 수정 화면의
"보기 내용 (선택)" 칸에 ① x+2, ② x+3 … 을 넣고 정답 번호를 고르면 된다.

```typescript
choices: null                      // ✅ 지면에 보기가 인쇄된 문제 (대부분)
choices: ['x+2','x+3','2x+1', …]   // ✅ 답이 수식이라 보기를 직접 만든 경우
```

⚠️ **학생 화면 라디오의 값은 언제나 '보기 번호'다.** 보기 내용을 값으로 쓰면
`normalizeAnswer` 가 문자열에서 첫 숫자를 뽑는 탓에 `x+3` 이 3번으로 읽혀 오채점된다
(`SolveProblem.tsx`). 보기 내용은 화면 표시용이고, 저장·판정은 번호로 한다.

### `title` — 자동 생성 형식
`"{교재} {과목} {문제번호}번"` (예: `"쎈 공통수학1 42번"`)

### `source_label` — 지면에 인쇄된 문제번호

크롭이 앵커로 읽은 번호를 **그대로** 담는다(쎈 `"0243"`, 내신 `"3"`). `problem_number`(순번)와
다르다. 빠른정답표가 이 번호로 되어 있어 **정답 자동 입력의 매칭 기준**이다.
못 읽은 번호(대표문제 배지 등)는 앞뒤가 연속이면 `infer_labels` 가 셈으로 채운다.

## 빠른정답 PDF 로 정답 자동 입력 (2026-08-27)

정답을 하나씩 타이핑하는 대신 교재의 빠른정답 PDF 를 한 번 읽어 채운다.

**답지를 넣는 곳은 두 군데다.**

- **교재 관리** — 교재 행이나 폴더 행의 ☑ 아이콘. 크롭 전에도 미리 넣어둘 수 있고,
  이미 저장된 답지가 몇 개인지 여기서 확인한다.
- **상세 입력** — "빠른정답으로 채우기". 저장된 답지로 이 작업의 문제를 채운다.

흐름:

1. 빠른정답 PDF 를 넣으면 **첫 쪽만 시험 삼아 읽는다**(비용 1~2회). 번호와 정답이 제대로
   잡히는지 보고, "전체는 6쪽·단 12개 → 최대 24회, 약 6분" 견적을 함께 보여준다.
2. 확인하면 **"나머지 전부 읽기"** → `answer_keys` 에 저장. 같은 PDF 를 또 올리면 해시로
   걸러 되묻는다(한 번 읽는 데 몇 분·수백 원이 든다).
3. 상세 입력의 검수 표(문제번호·지면번호·크롭 썸네일·정답)를 보고 **"N개 적용"**

### 답지의 범위 — 교재 전체냐, 이 회차냐 (2026-08-27)

| 범위 | 쓸 때 | 왜 |
|---|---|---|
| **교재 전체**(기본) | 쎈·기본서 | 번호가 책 전체에서 유일(0001~1316). 한 번 읽으면 **다른 단원은 공짜** |
| **이 폴더(회차/시험)** | 모의고사·내신 | 회차마다 1~30번이 겹쳐서, 교재 단위로 담으면 **앞 회차 답지를 덮어쓴다** |

폴더를 고르고 열면 그 폴더가 기본으로 잡히고, 모달에서 바꿀 수 있다. 조회는 **폴더 답지가
교재 전체 답지를 이긴다** — 그래서 쎈처럼 교재 전체로 넣어둔 답지는 어느 단원에서도 그대로 쓰인다.

객관식은 원문자를 번호로 바꿔 넣는다(`③` → `correct_answer="3"`, `answer_type="multiple_choice"`).
소문항 `(1)(2)`·한글·여러 값·두 번 읽어 다른 것은 검수 표에서 주황 배지로 튄다.

실측(쎈 공통수학1, 6쪽): 정답 1316개를 6분에 읽었고 0159~0278 매칭 120/120,
손볼 것 5개(0202·0215·0217·0246·0255).

## 교재를 단계별로 쌓기 (쎈 등, 2026-08-27)

쎈은 한 단원 안에 A/B/C단계가 이어져 있다. 폴더는 **단계를 위, 단원을 아래**로 둔다:

```
쎈_공통수학1_B,C단계
├ B단계
│  ├ 나머지정리와 인수분해   (0159~0255)
│  └ 다항식의 연산          ← 단원마다 이렇게 쌓는다
└ C단계
   ├ 나머지정리와 인수분해   (0256~0278)
   └ 다항식의 연산
```

교재 관리에서 `B단계` 를 고르면 하위 단원 문제가 다 보인다(`descendantIds`).

### 올리는 법 — 단계 폴더를 고르고 그 구간만 자른다

한 단원 PDF 에 B단계와 C단계가 같이 들어 있어도 나눌 필요가 없다.

1. 왼쪽 트리에서 **`B단계 > <단원>`** 폴더를 고른다 (없으면 만든다)
2. **PDF 가져오기** → 파일을 고르면 **단계 구간이 자동으로 잡힌다**
   (배너가 있는 쪽을 찾아 `1~13쪽` `14~17쪽` 처럼 보여준다)
3. 배너 그림을 보고 그 단계 구간을 누르면 시작/끝 쪽이 채워진다 → 업로드
4. `C단계 > <단원>` 폴더에서 같은 PDF 로 반복

⚠️ **배너 글자(B/C)는 기계가 안 읽는다** — 입체 일러스트라 OCR 이 못 읽는다. 그래서
그림을 보여주고 사람이 고르게 한다. 구간이 둘이고 폴더가 B/C단계면 순서대로 미리 골라
두지만, 그림이 같이 보이므로 틀렸으면 바로 바꾸면 된다.

### 이미 섞여 버렸다면

`python -m scripts.split_folder_by_label <폴더id> --into "B단계/<단원>=0159-0255" --into "C단계/<단원>=0256-0278" --delete-source --apply`

지면번호 범위로 갈라 `problems` 와 `problem_staging` 을 **둘 다** 옮긴다(CMS 의 폴더 이동은
`problems` 만 고쳐서 답지 스코프가 어긋난다). `--apply` 없으면 dry run 이고, 범위 밖 문제가
있으면 중단한다.
