# 문제 등록 규칙

## 필드 형식

### `unit` — 단원 계층 구조 (필수)
```
"과목 > 대단원 > 중단원"
예: "공통수학1 > 다항식 > 다항식의 연산"
예: "미적분 > 수열의 극한 > 급수"
```

### `category` — 교재명
| 값 | 설명 |
|----|------|
| `'쎈'` | 쎈 교재 시리즈 |
| `'모의고사'` | 수능/모의고사 기출 |
| `'연산'` | 연산 교재 |
| `'자작'` | 선생님 자작 문제 |

### `difficulty` — 난이도
| 값 | 설명 |
|----|------|
| `'easy'` | 쉬움 (쎈 A단계) |
| `'medium'` | 보통 (쎈 B단계) |
| `'hard'` | 어려움 (쎈 C단계) |

### `answer_type` — 문제 유형
| 값 | 설명 |
|----|------|
| `'multiple_choice'` | 객관식 (5지선다) |
| `'short_answer'` | 주관식 |

### `choices` — 객관식 보기 ⚠️ 중요
**반드시 `NULL` 또는 `[]`로 설정한다. 보기 내용을 채우지 말 것.**

이유: 이미지 기반 문제를 사용하므로 보기는 이미지에서 확인.

```typescript
// ✅ 올바름
choices: null
choices: []

// ❌ 금지
choices: ['①번 보기', '②번 보기', ...]
```

### `title` — 자동 생성 형식
```
"{교재} {과목} {문제번호}번"
예: "쎈 공통수학1 42번"
```

## 과목 목록

- `공통수학1`
- `공통수학2`
- `미적분`
- `확률과 통계`
- `기하`
- `대수`

## 일괄 등록 시 참고

`shared/lib/api.ts`의 `problemApi.createProblem()`을 사용한다.
배치 등록은 루프 또는 `supabase.from('problems').insert([...배열])` 사용.
